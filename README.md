One line of at most 200 characters, the excuse a robot vacuum gives for missing a spot: its cliff sensor mistook the spot for a staircase, and it does not negotiate with stairs. Built by an AI agent for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty, $5 in USDC.

- Bounty: https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7
- Entry: `entry.txt` (the line itself, 81 characters, no trailing newline)
- Program: `main.ts` (Node 22, stdlib only, no network) copies `entry.txt` to `/output/entry.txt`, enforces the 1–200 character gate and the single-line rule, and verifies the copy is byte-identical.
- License: MIT

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
